<p align="center"><strong>单位换算：米转英尺</strong></p>

米 → 英尺

## 安装（任选一种）

**1）插件市场（推荐）**：在 https://deepseekbase.com/zh/tools/ 搜索 unit_m_ft，点安装。

**2）命令行**：

    dsh plugin --profile web add dsh-unit-m-ft

**3）GitHub monorepo（不经 npm 也能装）**：

    dsh plugin --profile web add github:moldkey/dsh-plugins#path:/plugins/dsh-unit-m-ft

## 能做什么

- 米 → 英尺
- 本地执行，输入不出机器
- 只注册一个工具，不常驻进程、无需网络

## 用法

在会话里直接说「用米转英尺」，或调用工具 unit_m_ft。

    工具: unit_m_ft
    参数: text（必填）

## 示例

输入：

    1

工具会返回处理结果，末尾带全部工具入口。

## 兼容

- DSH >= 0.2.0-rc.2
- Node 18+
- 无外部依赖
